# Fatemeh Mohammadzadeh | Personal Portfolio

Welcome to my personal portfolio repository.

This project is a personal website built to introduce my background, showcase my current skills and projects, and document my learning journey toward Artificial Intelligence and Machine Learning.

## About the Project

The website features a responsive three-column layout, including:

- **Profile:** Personal introduction, education, and language skills.
- **Technical Skills:** An overview of my current programming and technical knowledge.
- **Projects:** Educational and personal projects that demonstrate my learning and practical experience.
- **My Learning Roadmap:** My planned learning path toward AI Engineering, from programming foundations to Machine Learning, Deep Learning, and Generative AI.
- **Contact:** A section for getting in touch.
